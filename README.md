# Champions Cup Soccer Bracket (React + Vite)

Animated Quarterfinals-to-Final soccer tournament bracket driven by an inline JSON dataset of match scores and final games.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. tests:
   ```bash
   node --test src/bracketData.test.js
   ```
